# ORBIT

ToDo・プロジェクト・ポモドーロ・復習・読書・習慣を一つの軌道上で管理する、スマホ向けの Web アプリ（PWA）。

## 📱 スマホで使う

### ▶ [https://kazuyan38.github.io/orbit/](https://kazuyan38.github.io/orbit/)

#### iPhone（Safari）

1. 上のリンクを Safari で開く
2. 下部の共有ボタン（□↑）→「ホーム画面に追加」
3. ホーム画面の ORBIT アイコンから起動（全画面で動き、オフラインでも使えます）

#### Android（Chrome）

1. 上のリンクを Chrome で開く
2. 右上のメニュー（⋮）→「ホーム画面に追加」または「アプリをインストール」

## 使い方

- 縦画面: ToDo。先頭タスクの ▶ で集中モード（ポモドーロ）
- 右上のボタン: 追加（＋）・統計・機能ランチャー（プロジェクト／復習／読書／習慣／スケジュール）・設定
- 左下のメモボタン: どの画面からでも思いつきをメモ（キーボードまたは音声）。一覧からタスクに変換できます
- 設定 → バックアップを書き出す（定期的に推奨）

## アカウント

ORBIT は招待制です。初回は「新規登録」で、管理者から受け取った招待コード・ユーザー名・パスワードを入力してください。
データは端末内に保存され、ログイン中はクラウドにも同期されるので、別の端末でも同じデータを使えます。
