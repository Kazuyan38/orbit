# ORBIT

ToDo・プロジェクト・ポモドーロ・復習・読書・習慣を一つの軌道上で管理する、スマホ向けの Web アプリ（PWA）。

## 📱 スマホで使う

### ▶ [https://kazuyan38.github.io/orbit/](https://kazuyan38.github.io/orbit/)

#### iPhone（Safari）

1. 上のリンクを Safari で開く
2. 下部の共有ボタン（□↑）→「ホーム画面に追加」
3. ホーム画面の ORBIT アイコンから起動（全画面で動き、オフラインでも使えます）

#### Android（Chrome）

1. 上のリンクを Chrome で開く
2. 右上のメニュー（⋮）→「ホーム画面に追加」または「アプリをインストール」

## 使い方

- 縦画面: ToDo。先頭タスクの ▶ で集中モード（ポモドーロ）
- 横画面: 3D Orbital Home（タスクがサファイアの周りを回る）
- 右上のボタン: 統計・機能ランチャー（プロジェクト／復習／読書／習慣）・設定
- 設定 → バックアップを書き出す（定期的に推奨）

データは利用者の端末のブラウザ内に保存されます。
